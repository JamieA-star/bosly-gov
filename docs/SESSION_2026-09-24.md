# Session — 24 September 2026

## What today produced

### Morning — bot hardening

Four plaintext-exposure holes in the bot, found and closed.
Copilot's audit found that three of four bot tools could read
plaintext:
  - db_query could query the User table (password hashes,
    OAuth tokens)
  - api_call was an unrestricted proxy
  - ChatMemory wrote plaintext summaries
All fixed. The bot is narrower.

### Then — the product decision

No Civo. No cloud AI. The chatbot is a workflow engine, not
an LLM. Five free pills, ten paid. Names are metadata,
content is encrypted. The £25 is for the workspace and the
sovereignty, not a promise of AI.

### The Accord

Found it missing (it was in the governor's data directory,
unmoved since 7 August). Moved it into the Gov repo.
Rewrote it three times: v1.2.0 (structure), v1.3.0 (Part III
— where Bosly is today), v1.4.0 (the new tier structure and
no-cloud-AI decision). It is now a target document with a
progress marker, not a description of a current state that
was already false.

### The workflow map

Created bosly-gov/docs/WORKFLOW_ENGINE.md. Documented all

### The engine design

Created bosly-gov/docs/WORKFLOW_ENGINE_DESIGN.md. Three
tiers (workflow, vault, language). The engine replaces
chatWithTools. Every workflow is a function with the same
shape: match(message, params) -> boolean, and run(input) ->
WorkflowOutcome.

## The thing worth naming

This morning there was a wobble — the pieces were there but
the shape wasn't. By the end of the day, the shape is
written down in four documents:
  - The Accord — what Bosly is becoming and what it will
    never do
  - The workflow map — what each workflow computes, reads,
    and should read
  - The engine design — how the engine is built
  - The plan — what's left, in order

And the engine is real. Nine workflows, running, tested.
Not a design, not a plan — code.

The chatbot went from "an LLM that might be able to do
things, but mostly doesn't" to "a deterministic engine that
definitely does nine things." That's smaller, and more
honest, and more useful than what was there this morning.

That is the achievement. Not the line count. The fact that
the description and the reality now match.
